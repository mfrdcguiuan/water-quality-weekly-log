How this sheet works

Record the sub-sample counts for each tank and, for the 10 zoeae observed in each tank, how many are at each stage (Z1, Z2, Z3, Z4, M for megalopa, C1 for first crab); the six stage numbers should add up to 10. Estimated count = sum of the counts × multiplier; survival = estimated count ÷ stocked per tank. Saving again for the same date replaces that day.

Enter one value per box (or several separated by spaces; the app uses their mean). Saving again for the same date, session and unit replaces that reading. Change the unit names, target ranges and optional parameters in Settings.

How monthly sampling works

Once a month, measure a sample of animals from each unit. Choose the date and unit, then type or paste one animal per line with the measurements in the order shown (separate the numbers with spaces, tabs or commas). The app shows the mean, SD, minimum and maximum as you type. Saving again for the same unit and date replaces that sample. The Report page shows growth per day, specific growth rate and survival compared with the previous sampling.

Import from a file or your spreadsheet

Save or download your daily-record sheet as .xlsx or .csv (in Google Sheets: File, then Download), and choose it here. The app reads the tank rows (T1R1 to T4R3) from the daily block and calculates the daily means. If a tank and date are already saved, the imported values replace them, so you can import an updated file again at any time. For a .csv file, export the sheet tab you want.

Easiest way to import everything at once: download the CSV template, fill in one row per tank per day with all parameters in that row, save it as .csv, and choose it below. Your own sheet layout also works.

Or paste cells

In the sheet, select the daily block (the rows from T1R1 to T4R3, together with the row that shows the date), copy it, and paste it here. Daily means are calculated for you. If a tank and date are already saved, the pasted values replace them. If no date is found in the paste, the Date field above is used.
